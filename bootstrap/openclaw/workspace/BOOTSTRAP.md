# Workspace bootstrap

This workspace is created by the OpenClaw bootstrap script.

- `workspace-main` is the primary workspace for browser and web tasks.
- `workspace-resume` is reserved for resume generation and editing.
- `workspace-cover_letter` is reserved for cover-letter generation and editing.
- `workspace-repo_coordinator` is reserved for summarising isolated repo-worker
  reports; it never receives a repository checkout or credentials.

If you cloned this repo on a fresh machine, run the bootstrap script again
after restoring your local OpenClaw secrets bundle.
